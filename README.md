# 🌍 Nomad Guide

> Your personal travel companion for independent adventures.

---

## Overview

Nomad Guide is an open-source travel companion for independent travellers.

The goal of the project is to combine trip planning, travel documentation and personal travel memories in a single application.

The project is also a long-term learning journey focused on professional software engineering and modern web development.

---

## Planned Features

* 🗺️ Trip planning
* 📍 Places & points of interest
* 💰 Expense tracking
* 📷 Photo management
* 📖 Travel diary
* 🤖 AI-powered travel recommendations
* 🌐 Offline support

---
