# MVP

## Goal

Build the smallest possible version of Nomad Guide that already provides value for an individual traveller.

The first version should be usable during a real trip.

---

# Included

## Trips

- Create trip
- Edit trip
- Delete trip

---

## Places

- Add place
- Edit place
- Delete place

---

## Expenses

- Add expense
- Categories
- Amount
- Currency

---

## Photos

- Attach photos to places

---

## Notes

- Notes for places
- Notes for trips

---

## Travel Journal

- Daily journal
- Photos
- Text

---

# Not included

- AI
- Cloud Sync
- User Accounts
- Social Features
- Booking
- Maps
- Weather
- Recommendations
- Product Comparison

---

# Success

Version 0.1 is successful if one complete trip can be documented using only Nomad Guide.
